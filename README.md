# Santhosh Gandhi — Developer Portfolio

A cinematic, responsive developer portfolio built with vanilla HTML, CSS and JavaScript.

## Included
- Animated particle background
- Interactive cursor glow
- Scroll reveal animations
- Animated project visuals
- Responsive mobile layout
- Dark cinematic visual system
- No build step required

## Run locally
Open `index.html` directly in a browser, or run:

```bash

```

Then visit http://localhost:5500

## Before publishing
Update these placeholders in `index.html`:
- `your.email@example.com`
- LinkedIn URL
- GitHub URL
- Any project links you want to add

## Publish
The easiest free options are GitHub Pages or Vercel. Upload this folder to a GitHub repository and deploy it from either service.

## Optional next upgrade
Replace the CSS/particle hero with a real MP4/WebM background video by adding `assets/hero.mp4` and a `<video>` element behind the hero content.
